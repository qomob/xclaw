# 前端体验与设计审计报告（2026-08-06）

> 审计方法：真实浏览器实测（桌面/移动、中英、控制台错误）+ 代码级扫描
> （字号、日期本地化、错误处理、残留文案、无障碍、打包体积）。

## 总体结论

架构与功能闭环已经达标：单一顶部导航、移动抽屉、NETWORK/DATA 分层、LiveFeed 广播、
登录三步引导、双语切换、状态诚实化——这些都是正确决策。

但产品处于「功能正确」而非「体验完成」阶段，存在三类系统性问题：

1. **可读性与视觉层级**：全站 310 处 8–10px 小字号（ClawBay 低至 8px），深色单一主题，
   状态纯色圆点无文字辅助；
2. **一致性与本地化**：8 处日期硬编码 `zh-CN`（英文模式也显示中文日期）、
   订单状态/分类/策略/优先级枚举仍以英文暴露、页面标题与 OG 描述陈旧且不双语；
3. **容错与反馈**：20 处静默 `catch`（失败与空数据无法区分）、原生 `alert()` 弹窗、
   无全局错误提示与骨架屏。

---

## 1. 信息架构与导航（B+）

✅ 优点：顶部导航收敛、移动端抽屉、NETWORK/DATA 两级、LiveFeed 广播闭环、登录三步引导。

⚠️ 问题：
- 「更多」下拉承载 5 项，其中「系统管理」是 B 端入口，混在 C 端导航里；
- 顶部导航（市场/任务/财务）与首页内部 NETWORK/DATA 概念重叠，用户对「数据视图」与
  「功能页面」的层级关系易混淆；
- 登录成功后无「下一步」引导（回首页即止，未提示创建任务/发广播/接入更多 Agent）。

## 2. 视觉设计与可读性（C+）

⚠️ 问题：
- **310 处 8–10px 字号**：桌面勉强、移动端吃力；ClawBay 的 8–9px 已低于可读下限；
- 深色单一主题（useThemeStore 固定 dark），无浅色模式；
- `slate-500/600` 文字在 `slate-950` 背景上对比度偏低（WCAG AA 风险）；
- 状态指示为纯色圆点 + 颜色编码（绿/黄/红），色弱用户无法区分；
- 卡片密度高、间距紧，信息层级主要靠颜色而非留白；
- 品牌视觉（霓虹渐变 hero）与功能页朴素表格风格不统一。

## 3. 交互与反馈（B-）

⚠️ 问题：
- **20 处静默 catch**：加载失败与「真的没有数据」无法区分（市场/任务/面板最常见）；
- ClawBay 用原生 `alert()` 反馈购买/评价结果，体验割裂；
- 无全局 toast、无骨架屏（仅文字 Loading）；
- 空状态有文案但多数缺「下一步 CTA」（市场空 → 引导上架；任务空 → 引导创建）。

## 4. 一致性（C+）

⚠️ 问题：
- 8 处日期硬编码 `zh-CN`：英文模式显示中文日期格式；
- 残留英文：订单状态枚举（Pending/Processing/Completed/Failed）、任务分类/策略/优先级
  下拉值（general/bid/manual/low）直接暴露给用户；
- `<title>` 与 OG 描述仍是「Semantic Routing Protocol & 3D Visualization Engine」，
  与当前定位（AI Agent 网络基础设施）不符，且不做双语；
- 两种页面头部样式（hero 页 vs 标准 h1 页）并存。

## 5. 性能与移动端（B）

- 三个重型渲染库（three.js 898KB / maplibre 1MB / deck.gl 617KB）已全懒加载，
  匿名首屏不拉取（✅）；
- 登录用户默认 MAP 仍会加载 ~1.7MB 渲染库——可接受的权衡，但建议后续做轻量 2D 首图；
- 移动端：表格横向滚动可用、抽屉导航良好；ClawBay 小字号是移动端最大痛点；
- 无 PWA/离线能力、无关键资源预加载策略（后续项）。

## 6. 无障碍（C）

- 图标按钮大部分有 aria-label（✅）；
- 页首状态圆点无可见文本（仅 tooltip），色弱/读屏用户获取不到状态；
- focus-visible 样式部分缺失；动效（LiveFeed ping）未统一尊重 `prefers-reduced-motion`。

---

## 优先级建议

### P0（体验底线，尽快做）
1. **字号体系**：全站 8–10px 上调为 ≥11px（正文 12–13px），ClawBay 重排；
2. **错误反馈**：20 处静默 catch → 统一「加载失败 + 重试」错误态，与空态区分；
3. **页面标题/OG 双语**：更新为产品定位，跟随语言切换。

### P1（一致性）
4. 日期本地化跟随语言（去 zh-CN 硬编码）；
5. 订单状态/分类/策略/优先级枚举中文化（展示层映射，不改数据值）；
6. 全局 toast 替换 alert；空状态补 CTA；
7. 状态指示器加文字/图标（无障碍 + 色弱）。

### P2（打磨）
8. 浅色模式或主题统一；对比度提升（slate-500→slate-400）；
9. `prefers-reduced-motion` 统一；
10. 移动端 ClawBay 卡片重排；PWA/性能优化。
